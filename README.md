Course: ITA2376 Deep Learning  
Assignment: A02 – Comparative Analysis of Machine Learning and Deep Learning Tools and Frameworks

Project Description
This repository contains the group research and contributions for Assignment A02. The project focuses on comparing Machine Learning and Deep Learning tools and frameworks.
Each team member contributes research, analysis, and practical applications related to the selected tools and frameworks.

Project Objectives
Research selected Machine Learning and Deep Learning tools.
Compare their main features and advantages.
Analyze usability, performance, automation, and scalability.
Identify real-world applications.
Develop practical examples and use cases.

Team Contributions
Each team member will upload their individual contribution to this repository.

Repository Contents
This repository will include:
Comparative analysis documents
Individual contribution journals
Research materials
Practical applications
Code or notebooks, if applicable
Final project documentation
